# 🏢 OmniLar

**Gestão inteligente. A tranquilidade da Baixada Santista para o seu condomínio.**

## 😩 O problema

| | Desafio | Na prática |
|---|---|---|
| 1️⃣ | **Comunicação informal** | Avisos no WhatsApp e papel colado no elevador |
| 2️⃣ | **Baixa rastreabilidade** | Manutenções e ocorrências sem registro, sem prazo e sem dono |
| 3️⃣ | **Conflitos na alta temporada** | Moradores e hóspedes disputando vagas, áreas comuns e silêncio |

## 🎯 Objetivos

- **Centralizar** a gestão de condomínios na Baixada Santista.
- **Promover** uma comunicação eficiente entre síndicos e moradores.
- **Adequar** o sistema a empreendimentos de portes e infraestruturas diferentes.

## ✨ Diferenciais

| | Funcionalidade | O que faz |
|---|---|---|
| 🗳️ | **Assembleia digital** | Pautas ordinárias e extraordinárias, quórum mínimo, comentários e votação direto pelo sistema |
| 🔑 | **Check-in digital de visitantes** | Convite com QR code, aprovação do morador e validação na portaria |
| 🚗 | **Gestão de vagas** | Mapa da garagem, registro e aviso de vagas de estacionamento |
| 🔄 | **Vagas flexíveis** | Fila de alocação e reservas temporárias, com controle digital e registro automático de uso |
| 📊 | **Contas visuais** | Receitas, despesas e cobranças acompanhadas em tempo real |
| 💸 | **Cobrança automática** | Emissão de boletos individual ou em lote, lembretes de vencimento e acompanhamento da carteira |

## 🧭 Tudo o que o sistema tem

| Área | Módulos |
|---|---|
| **Comunicação** | Avisos com tipo e data de expiração · Assembleia digital · Chat |
| **Comunidade** | Visitantes por QR code · Encomendas da portaria |
| **Áreas comuns** | Agendamentos com calendário (salão de festas, piscina, sala de reuniões) · Garagem |
| **Operações** | Ocorrências com protocolo, prioridade e status · Manutenção com mapa e fluxo sugerido |
| **Gestão** | Mapa do edifício (torres, andares, unidades, proprietários e inquilinos) · Moradores e convites · Fornecedores |
| **Financeiro** | Visão geral · Contas · Balancete · Emissão de boletos |
| **Plataforma** | Vários condomínios por conta, perfis de administrador, síndico e morador, e planos por porte |

## 💼 Modelo de negócio

Assinatura mensal por condomínio, com planos por porte:

| Plano | Preço | Limites |
|---|---|---|
| **OmniGO** | R$ 109,99/mês | Até 20 moradores e 1 síndico · avisos, financeiro e agendamentos |
| **Omni+** | R$ 169,99/mês | Até 100 moradores e 3 síndicos · + ocorrências, relatórios financeiros e suporte prioritário |
| **OmniUltra** | Sob consulta | Moradores e síndicos ilimitados · + relatórios avançados e suporte dedicado |

Planos anuais saem com desconto (R$ 91,66/mês no OmniGO e R$ 141,66/mês no Omni+).

<sub>Valores configurados no protótipo, a validar com os primeiros condomínios.</sub>

## 🛠️ Como foi construído

Desenvolvido pelo Grupo 4 no Projeto Integrador 2, com vibe coding usando **Claude Code** e **Codex**.

- **Front:** React 19 + TypeScript + Vite, Tailwind CSS, React Router, gráficos com Recharts e leitura de QR code com jsQR
- **Back:** API em Fastify com JWT, e Supabase (Postgres, autenticação, migrações e Edge Functions para o fluxo de visitantes)
- **Deploy:** Vercel

<details>
<summary><b>👩‍💻 Para desenvolvedores: rodar o projeto</b></summary>

### Pré-requisitos

- Git
- Node.js (versão LTS)
- VS Code (opcional)

```bash
git --version
node -v
npm -v
```

### Rodar o frontend

```bash
git clone https://github.com/joaoteixeirap/OmniLar.git
cd OmniLar/apps/web
npm install
npm run dev # http://localhost:5173
```

### Rodar o backend

```bash
cd apps/backend
npm install
npm run dev   # servidor Fastify em modo watch
npm run seed  # dados iniciais
```

### Estrutura

```
apps/
├── web/        # frontend React (pages, routes, features, components)
├── backend/    # API Fastify (routes, middleware)
└── supabase/   # migrações e Edge Functions (fluxo de visitantes)
```
